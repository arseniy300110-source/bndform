# bndform

Сайт BND.FORM — кастомные ремешки для WHOOP 5.0 и MG.

- `index.html` — основной сайт (о нас, конструктор ремешка, как заказать, FAQ, контакты)
- `links.html` — короткая страница со ссылками на соцсети

Статический сайт без сборки: подходит для GitHub Pages (Settings → Pages → Deploy from branch).
